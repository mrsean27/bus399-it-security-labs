# IT Infrastructure and Security: Labs and Risk Analysis

Cal Poly San Luis Obispo, BUS 399 IT Infrastructure and Security, Fall 2022. Individual coursework by Sean Wood.

**Topics:** packet capture and traffic analysis (Wireshark, FTP vs SFTP, SSH), vulnerability assessment, access controls, attack vectors, security monitoring and logging, qualitative and quantitative risk analysis, business-continuity planning, and a web attack write-up (XSS, SQL injection, buffer overflow).
